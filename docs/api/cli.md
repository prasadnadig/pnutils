# `pnutils-k8s` CLI

The console entry point is documented from its implementation. The executable
supports environment-backed Opaque Secrets and TLS Secrets; see the
[Kubernetes module guide](https://github.com/prasadnadig/pnutils/blob/main/src/pnutils/k8s/README.md)
for safe preview, confirmation, backend, and secret-handling behavior.
